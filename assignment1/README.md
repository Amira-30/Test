Website

A personal portfolio website built mainly with HTML, with a small part of CSS for styling.

📋 Description

This project is a portfolio page/website that showcases personal information, skills, and work in a simple and straightforward way, using HTML with light styling touches from CSS.

📁 Project Structure

``` Test/ ├── css/ # Simple styling files ├── images/ # Images used in the website ├── # Fonts used ├── doc.html # Additional page / documentation └── index.html # Main portfolio page ```

🚀 How to Run
Clone the repository: ```bash git clone https://github.com/Amira-30/Test.git ```
Open the `index.html` file directly in any browser
No additional installation is needed — the site runs entirely in the browser
🛠️ Technologies Used
HTML5 – Website structure
CSS3 – Basic styling for colors and layout
